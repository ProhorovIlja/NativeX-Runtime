## Source-grounded upstream review, without importing incompatible implementations

- [R0Y00/Xbox2Windows PR #394](https://github.com/R0Y00/Xbox2Windows/pull/394), MIT: author reports distinction between **native EXE entry returning to the OS vs. mapped image entry returning to the host**, with worker lifetime and pipe EOF tests. Our current native PE loader exits 42–47, but **does not yet verify worker/EOF/ExitProcess parity for a Game Core image**.
- [Xbox2Windows PR #413](https://github.com/R0Y00/Xbox2Windows/pull/413), MIT: author found a conditional x64 Jcc whose target is also fallthrough; optional AOT lifting emitted an undefined C++ label. We prefer direct host x86-64 instruction execution whenever native target semantics permit, so AOT limitations are not automatically game runtime problems. Keep as an optional translator negative case.
- [Xbox2Windows PR #415](https://github.com/R0Y00/Xbox2Windows/pull/415), MIT: author's shared x86-64 AOT lifter adds XLATB semantics with zero-extended AL and special address-size prefix; **author reports 21,504 native/translated/reference cases**. This is not our independently executed title code and does not justify CPU emulation.
- [Xbox2Windows PR #410](https://github.com/R0Y00/Xbox2Windows/pull/410), MIT: failed pixel disassembly is a **PSO blocker**, not simply missing data. This informs future GPU pipeline readiness error states.
- [microsoftconnect/GameInput PR #63](https://github.com/microsoftconnect/GameInput/pull/63) includes the MIT DualSense companion adaptive-trigger helper, but **no physical controller has been driven by our CI**. Our verified GameInput v4 source test only validates API signatures and invalid parameter bounds.
- [microsoft/DirectStorage](https://github.com/microsoft/DirectStorage), MIT; [KhronosGroup/Vulkan-Samples](https://github.com/KhronosGroup/Vulkan-Samples), Apache-2.0; [libsdl-org/SDL](https://github.com/libsdl-org/SDL), Zlib: candidate reusable implementations are available but require **task-specific benchmarking and platform integration**, not indiscriminate copying.
- [NVIDIA-RTX/Streamline](https://github.com/NVIDIA-RTX/Streamline), [intel/xess](https://github.com/intel/xess), and [AMD FidelityFX SDK](https://github.com/GPUOpen-LibrariesAndSDKs/FidelityFX-SDK): public feature/provider candidates with separate SDK redistribution, driver/device prerequisites. A `NOASSERTION` GitHub license marker is **not** permission to redistribute all DLLs. DLSS 5 neural rendering is not a guaranteed compatible replacement for DLSS Super Resolution, and neither DLSS, XeSS, FSR, Reflex nor a DirectStorage GTA data path has been integrated.
- [XCL](https://github.com/ivall/xcl) GPL-2.0 and [AnyXboxX](https://github.com/LooperSalty/AnyXboxX) GPL-3.0 can be studied and separately source-built under their respective obligations; proprietary-title or unlicensed TomBox code must not be silently merged into this MIT repository.

## Windows native loader acceptance path

1. For source-built **legal, testable Windows/GDK samples**, compare PE section protections, forwarder/name/ordinal/delay import resolution, relocations, TLS initialized data/callback attach and detach, `.pdata` registration and exception unwinding between **ordinary Windows OS LoadLibrary/EXE startup** and an independent manually mapped path. Run both tests on same OS/architecture with deterministic markers and finite timeouts.
2. For a lawfully available Xbox Series X build, make an actual **PE/GDK import inventory** without executing unknown code, record game title/build identifiers, inspect exact console D3D12.X and memory ABI structures and only then plan compatible native Windows adapters.
3. Render source-built test scenes through host D3D12 (already achieved under WARP with GPU block compression/CPU reference) and validate actual Xbox RDNA2 shaders, descriptors, 64 KiB GPU memory coherence, texture swizzles and frame output on real physical GPUs.
4. Implement game-aware streaming, audio/video and safe save recovery, native Raw Input/GameInput controller mapping, performance metrics and optional licensed FSR/XeSS/DLSS/Reflex/DirectStorage integration **only after verifying actual scene and codec data**. Keep the native Linux ELF/Vulkan route separate from Proton; build co-op only after full Windows single-player coverage.

No background service, leaked file acquisition, scheduled GitHub Actions, auto-research monitor, game binary redistribution or silent GPL-source graft was introduced.
