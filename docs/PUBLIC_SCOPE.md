# Public project scope and provenance

NativeX Runtime publishes generic x64 platform research, reusable original source, reproducible synthetic or appropriately licensed samples and evidence-based technical reports.

## Public deliverables

- Bounded metadata readers and offline dependency checks.
- Source-built host ABI, memory, graphics, audio, input, persistence and I/O fixtures.
- Reviewed upstream references, license notices and separately validated improvements.
- Manual build/test instructions and truthful evidence limitations.

## Materials excluded from the public source tree

Do not commit or publish proprietary game binaries, assets, SDKs, firmware, keys, account data, crash dumps, confidential analysis inputs, or unlicensed extracted code. Keep authorized external test inputs outside the Git checkout. Private storage is not a grant of permission to acquire, copy, modify, or use material. No access-control or DRM bypass is part of the public acceptance criteria.

## History and provenance

Formerly named Scarlett Windows Compat. Previous title-specific planning documents and engineering chronology are preserved in the original, unmodified [2026-11-23 revision](https://github.com/ProhorovIlja/NativeX-Runtime/tree/14a8806993bcd73887c63c5261ae4d62598f759b). Five application-specific planning documents were retired from the active documentation, and copies of the prior documentation were preserved separately. Historical technical reports may still mention earlier research cases and retain their original attribution and caveats.

The independently authored PE tools from [the prior feature revision](https://github.com/ProhorovIlja/NativeX-Runtime/tree/005b5923cd79a0a264ab6191e46c399804346cac) were incorporated by matching Git blob identity for the source and tests; private input inventories and title-specific audit reports are not incorporated. No force push, history rewrite or deletion of old commits is involved.

Evidence categories: upstream claim, source review, synthetic fixture, native host reproduction, and application-specific verification. Never conflate these categories.

No scheduled or background work is authorized by this repository policy.
