# Second-pass public native PC upstream audit — 2026-11-22

**Scope:** GitHub public repositories and merged PR descriptions inspected in this development session. This report separates externally authored findings from our own executable tests. No GTA VI game assets/executable were obtained or required, and no third-party GPL source was copied into the MIT project. Merely adding all code from every fork would create ABI, licensing, runtime and test conflicts; each integration needs an independent acceptance gate.

## Licensing boundary

The upstream [AnyXboxX THIRD_PARTY.md](https://github.com/LooperSalty/AnyXboxX/blob/1a2e2e677c18e6ae4053eb84d4ff2395c538c108/THIRD_PARTY.md) states its **2026-11-21 main-license transition to GPL-3.0-or-later** from LGPL-2.1-or-later. Leonida-derived components are GPL-3.0. XCL is GPL-2.0 according to the pinned registry; Sony, Microsoft and NVIDIA provider code may have separate non-MIT terms. Keep LGPL/GPL source out of an MIT-only bundled runtime unless a legal distribution model has been chosen and all obligations met. The current test fetches public source to a temporary CI folder and does not publish it as our binary.

## Highest leverage next engineering gates

- A real, lawful Xbox Series build's EXE imports and console-specific ABI/PE handling before declaring any title-compatible loader.
- Console D3D12.X command and RDNA2 memory/shader instruction traces with **verified CPU/GPU reference output**, not fabricated synthetic packet layouts. Particular care needed for wave32/64 and indexed atomics across WARP/AMD/NVIDIA/Intel devices.
- Windows user-visible D3D12 Present and native Linux Vulkan graphics raster/readback/WSI, then actual scene-guides for official FSR/DLSS/XeSS, frame generation and vendor latency APIs. A DLL or mod alone is not a renderer integration; optional DLSS5 cannot be assumed available/licensed simply from GitHub.
- Production audio I/O (WASAPI shared mode, event stream, hotplug, real playback) and video decoding only after verifying actual formats; input physical-device acceptance for DualSense, Xbox and generic HID.
- Real asset layout and benchmarking for DirectStorage vs IOCP/OS-thread reader, plus a Linux native io_uring variant. Preserve integrity, bounded work queues, cancellation and compatibility with supported systems.

None of these steps requires or presupposes pirated game materials. No new scheduled monitoring or background jobs were created in this development batch.
